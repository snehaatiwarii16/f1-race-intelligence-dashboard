# Formula 1 Race Intelligence Dashboard Analysis Report (2010–2026)
**Objective:** Demonstrate interactive motorsport analysis concepts using dashboard views for team points, driver performance, tyre mix, DNF categories, and season participation.

**Tools:** HTML, CSS, JavaScript, CSV; Tableau-ready data layout.

**Limitation:** This prototype uses synthetic illustrative data. It does not represent verified official F1/FIA results, championship points, tyre strategies, or failure rates.
